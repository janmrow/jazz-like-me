# Product

## Promise

> Find up to three jazz albums that fit your mood.

## Core user flow

1. Open the app.
2. Select one or more discovery tags.
3. Receive up to three jazz album recommendations.

## Current scope

- A calibrated catalogue of 30 real jazz albums.
- Discovery tags across three perceptual axes: energy, valence, and complexity.
- Categorical tags for instrumentation and performance context: vocal, piano-led, live.
- Simple, explainable scoring: closer EVC match and more trait matches rank higher.
- A minimal, responsive web UI.
- Fastify API backed by SQLite.

## Non-goals

- No user accounts or authentication.
- No social features, playlists, or sharing.
- No payments or admin panel.
- No external music APIs (Spotify, Discogs, MusicBrainz).
- No LLM dependency for recommendations.
- No cover images or long editorial descriptions in the first slice.
